## ▶️ How to Run

Make sure Java/JDK is installed on your computer.

Compile a Java file:

```bash
javac FileName.java
```

Run the compiled program:

```bash
java FileName
```

For example:

```bash
javac SimpleCalculator.java
java SimpleCalculator
```
